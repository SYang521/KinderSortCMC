\# KinderSort Benchmark Evaluation



This folder contains the files and documentation required to evaluate

KinderSort image-sorting accuracy in a reproducible manner.



The benchmark evaluator compares the identities expected in a

ground-truth CSV file with the folders generated by KinderSort.



\## Purpose



The benchmark workflow is used to measure and compare:



\- Original KinderSort baseline accuracy

\- Improved KinderSort accuracy

\- Unmatched image count

\- Wrong-identity classification count

\- Partial or additional identity matches

\- Unexpected files in the output folder



The original system and improved system must be evaluated using the

same benchmark dataset, ground truth, evaluation method, and test

computer.



\## Files



\### benchmark\_evaluator.py



The main evaluation program is located in the repository root.



The evaluator:



1\. Reads expected identities from a ground-truth CSV file.

2\. Scans the KinderSort output folders.

3\. Reconstructs original image filenames.

4\. Compares expected and actual identity sets.

5\. Calculates exact-match accuracy.

6\. Exports detailed evaluation results.

7\. Exports benchmark summary metrics.

8\. Detects unexpected output files.



\### ground\_truth.example.csv



This is a public example showing the required CSV structure.



It does not contain real names, private test information, or

photographs.



\### Private benchmark files



The following files are excluded from Git version control:



\- `ground\_truth.csv`

\- Generated detailed evaluation CSV files

\- Generated summary CSV files

\- Test photographs

\- KinderSort output folders



These files must remain outside the public repository unless all

information has been anonymized and approved for publication.
